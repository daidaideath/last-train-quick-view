# 終電時刻 再照合記録（2026/10/29）

index.html に載っている終電時刻を、2026年10月29日に公式時刻表と照合した結果。作業はクラウド環境からの自動取得で、取得できなかった出典は未照合のまま残している（推測で埋めていない）。

## 結論

- 照合できた範囲で、公式時刻表と食い違っていたのは**桜上水駅の1件だけ**。index.html を修正した。
  - 京王線 上北沢発の最後の桜上水行（平日）：0:35発 → **0:36発**（桜上水着の見込み 0:37ごろ → 0:38ごろ）
  - 原因：京王電鉄が2026年8月17日（平日）・8月16日（土曜・休日）に時刻表を改正していた。index.html は2025年3月15日改正の時刻表に基づいていた。
- JR東日本は、現在公開中の時刻表（URL上の版は `2611`）で照合し、照合した12駅すべてで一致した。
- 秋葉原駅は、index.html の値（京浜東北線南行 0:28 蒲田行など）が現在の公式時刻表と一致した。6月18日作成のレポート（0:42 品川行など）の値は現行の時刻表と合わない。
- 全項目を照合できたのは、経堂・桜上水・三鷹・赤羽・大崎の5駅。東京メトロ・東急・京急の時刻は取得できず、1件も照合できていない。

## 照合できなかった理由

| 出典 | 状況 |
|---|---|
| 東京メトロ（www.tokyometro.jp） | 自動アクセスに対して HTTP 403（サイト側のボット対策） |
| 京急（www.keikyu.co.jp） | 同上 |
| 東急・小田急の時刻表画面（transfer.navitime.biz） | 同上。小田急は駅別の印刷用PDFで代わりに照合できた |
| 都営地下鉄（www.kotsu.metro.tokyo.jp）の一部ページ | ボット確認ページが返り、時刻表が取得できない（取得できたページは照合済み） |
| ゆりかもめ | 時刻表の中身を `ykm.jcld.jp` から読み込んでおり、このドメインが許可リストにない |
| 東武（www.tobu.co.jp） | 接続が途中で切れる |
| 京成本線・金町線（keisei.ekitan.com） | 駅別時刻表で京成高砂を選ぶと北総線しか表示されない |
| 西武池袋駅発、TX | index.html の出典に該当する時刻表ページのURLがない |

ボット対策で止められたサイトについて、対策を回避する取得はしていない。未照合の分は、PCのブラウザで `docs/再照合チェックリスト_20261029.md` を使って確認する必要がある。

## 照合方法

- JR東日本：各駅の時刻表一覧ページから現行版の時刻表ページ（`/2611/timetable/...`）を取得し、22時以降の発車時刻・行き先・種別を抜き出して index.html の表と突き合わせた。
- 小田急：駅別の印刷用PDF（`/station/pdf/<駅>.pdf`）を画像にして読み取った。
- 京王・東京モノレール・ゆりかもめ・京成：公式サイトから案内される時刻表ページを、ブラウザで表示した内容から読み取った。
- 都営・りんかい線・西武：公式時刻表ページのHTMLから読み取った。
- 到着見込み（「〇〇ごろ」）は、index.html と同じく隣駅の公式発車時刻を元データとして照合した。所要時間の前提は変えていない。
