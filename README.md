# 終電クイックビュー

仕事中に終電時刻を素早く確認するための静的HTMLと、関連する駅別レポート・詳細画像を管理する案件です。

正式な作業場所は、作者PC内の案件フォルダ「終電クイックビュー」です。チャイム・通知・音声再生機能は使用しません。

## 主なファイル・フォルダ

- `index.html`：22駅をまとめた終電クイックビュー
- `index_detail_visual.html`：詳細ビジュアル版
- `output/駅別終電クイックビュー_公開版_20261029_保留解消.html`：最新版（掲載22駅を照合済み、清澄白河・池袋の保留を解消）
- `output/駅別終電クイックビュー_公開版_20261029_追加再照合.html`：前版（上書きせず保存）
- `駅別終電クイックビュー_公開版_20261029.html`：前版（上書きせず保存）
- `駅別終電クイックビュー_公開版_20260618.html`：旧公開版（21駅。上書きせず保存）
- `reports_business/`：駅別の業務向け終電調査レポート（22駅）
- `visuals_detailed/`：駅別の詳細画像（22駅）
- `docs/`：再照合チェックリスト、再照合記録、版差分メモ
- `tools/check_data.js`：データの形・リンク先・駅の揃いの点検（`node tools/check_data.js`、出典URLの到達確認は `--online`）
- `tools/make_checklist.js`：index.html から再照合チェックリストを生成
- `AGENTS.md`／`CLAUDE.md`：AI作業時の案件ルール

静的HTMLのため、通常の閲覧に依存パッケージのインストールやビルドは不要です。

## 更新ルール

- 終電時刻は公式情報など、出典を確認できるデータだけを使う。
- 読めない時刻や不明な値を推測で補完しない。
- 公開版HTMLは上書きせず、更新日を付けた別名で保存する。
- チャイム・通知・音声再生機能は追加しない。再追加はユーザーから明示的な依頼がある場合だけ行う。
- 公開前にPC表示とスマートフォン表示の両方を確認する。
- データを直したら `node tools/check_data.js` を実行し、エラーがないことを確認する。
